Question One

Explain your workflow when you use AI to build.

01

Understand & Plan

I break the task into clear subtasks and define acceptance criteria first. I use AI (Claude/Gemini) to brainstorm architecture options, identify edge cases, and evaluate trade-offs — e.g., "what are the pros/cons of SSR vs CSR for this use case?"

Gemini Claude Architecture Review
02

Build with AI as Co-pilot

I use AI coding assistants for boilerplate, repetitive code, and complex logic scaffolding. But I always review every line — AI is my accelerator, not my driver. I keep the context tight: specific files, clear prompts, and iterative refinement.

Copilot Antigravity IDE Code Review
03

Verify & Iterate

I test manually and write automated tests. I never ship AI-generated code without verifying it myself. If there's a bug, I debug it logically — not by blindly asking AI to "fix it."

Unit Tests Manual QA Logical Debugging
💡

Key Principle

AI saves me 40–60% of coding time, but I own 100% of the decisions. I treat AI output like a junior dev's PR — always review, often refine, sometimes reject.
